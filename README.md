# 🚀 Зазывала 2.0 (Zazyvala Telegram Tag Bot) • Vercel Serverless Edition

Высокопроизводительная, масштабируемая копия популярного бота **«Зазывала»** (`@ZazyvalaTag2Bot`, `@zazyvala`), специально переписанная и оптимизированная под **самые жесткие лимиты Vercel** (Hobby Plan 10 секунд, 1024 MB RAM, stateless serverless функции, холодный старт, квоты базы данных).

---

## ⚡ Почему оригинальные боты падают на Vercel и как это решено здесь?

1. **Таймаут выполнения 10-15 секунд (Vercel Serverless Function Timeout)**:
   - *Проблема*: Если в группе 50-100 участников, рассылка нескольких пачек сообщений с задержками для обхода лимитов Telegram (20 сообщ/мин) мгновенно убивает серверную функцию Vercel с ошибкой `504 Gateway Timeout`.
   - *Решение*: Использование официального механизма **`waitUntil`** (`@vercel/functions`). Вебхук Telegram мгновенно получает ответ `200 OK` за **~15 мс**, а отправка последующих пачек завершается в фоновом контексте без блокировки вебхука и повторных ретраев со стороны Telegram.

2. **Проблема исчерпания пула соединений БД (Connection Pool Exhaustion)**:
   - *Проблема*: Стандартный PostgreSQL/MySQL открывает соединение на каждый serverless-инстанс, что быстро исчерпывает лимиты бесплатных баз.
   - *Решение*: Хранилище на базе **Upstash Redis / Vercel KV** (`@upstash/redis`). Все операции работают по **HTTP REST API**:
     - 0 открытых TCP сокетов
     - 0 задержек на рукопожатие
     - Все профили участников чата загружаются **за 1 HTTP-запрос через Redis Pipeline** (~10-20 мс)
     - Атомарный кулдаун через нативный Redis TTL без лишних запросов к базе.

3. **Лимит Telegram на Push-уведомления (Push Mention Limit)**:
   - *Нюанс*: Telegram отправляет пуш-уведомления максимум **5 пользователям в одном сообщении** при массовом теге без юзернеймов / через ссылки.
   - *Решение*: Умное разбиение списка на настраиваемые пачки (по умолчанию по 5 человек). Это гарантирует, что **100% участников получат звуковое уведомление**.

4. **Засорение чата длинными списками никнеймов**:
   - *Решение*: Поддержка **Скрытого режима (Hidden / Zero-Width)**. Бот прикрепляет невидимые zero-width пробелы `&#8203;` со ссылками на участников к вашему тексту. Пользователи получают пуш с упоминанием, а в чате виден только чистый текст объявления!

5. **Статистика и уважение к личным границам**:
   - Команды `/out` и `/in` позволяют участникам отписаться от общих вызовов, защищая бота от жалоб на спам.
   - Команда `/setme` позволяет установить личный позывной/эмодзи.

## 📋 Список команд бота

### 📢 Вызов участников
| Команда | Описание |
| :--- | :--- |
| `/all [текст]` или `/tag` | Созвать всех активных участников группы пачками по 5 чел. |
| `/admins [текст]` или `/admin` | Созвать только администраторов группы (прямой запрос к API) |
| `/call <список> [текст]` | Созвать определенный пользовательский список участников |

### 👤 Персональные настройки участников
| Команда | Описание |
| :--- | :--- |
| `/setme <позывной>` | Установить личный позывной/эмодзи (например: `/setme ⚡ Тор` или `/setme 🎮 ProGamer`) |
| `/setme -` | Сбросить позывной |
| `/out` или `/optout` | Исключить себя из вызовов `/all` (вас больше не будут тегать) |
| `/in` или `/optin` | Вернуть себя в список вызовов `/all` |
| `/me` | Посмотреть свой текущий статус, позывной и настройки в этом чате |

### 📋 Пользовательские списки
| Команда | Описание |
| :--- | :--- |
| `/lists` | Посмотреть все списки участников в чате |
| `/create_list <имя> [описание]` | Создать новый список (например `/create_list dota Команда по Доте`) |
| `/add_to_list <имя>` | Добавить пользователя в список (ответом на его сообщение) |
| `/remove_from_list <имя>` | Удалить пользователя из списка |
| `/delete_list <имя>` | Удалить список целиком (доступно создателю или админам) |

### ⚙️ Администрирование чата
| Команда | Описание |
| :--- | :--- |
| `/settings` | Интерактивное меню с Inline-кнопками: переключение режима, кулдауна, размера пачки, прав доступа |
| `/stats` | Подробная статистика: сколько человек в базе бота, сколько активных, сколько отписалось |
| `/help` | Полная иллюстрированная справка по всем функциям |
| `/start` | Приветствие и кнопка быстрого добавления в группу |

## 🛠️ Быстрый запуск на Vercel (пошагово)

### Шаг 1: Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot` и задайте имя и юзернейм (например, `MyZazyvalaBot`).
3. Скопируйте полученный **`BOT_TOKEN`**.
4. **Важно для работы в группах**:
   - В @BotFather отправьте `/setprivacy`.
   - Выберите вашего бота.
   - Установите статус **`Disable`** (чтобы бот мог пассивно видеть сообщения в чате и автоматически наполнять базу участников без ручного добавления каждого).
   - В `/setjoingroups` убедитесь, что включено **`Enable`**.

### Шаг 2: Создание бесплатной базы данных Upstash Redis
1. Перейдите на [console.upstash.com](https://console.upstash.com/) (бесплатно, до 10 000 команд в день).
2. Нажмите **Create Database**, выберите регион, близкий к региону Vercel (например, Frankfurt `eu-central-1`).
3. В разделе **REST API** скопируйте:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`

*(Примечание: Если вы подключаете Vercel KV через панель Vercel Storage, эти переменные выставятся автоматически).*

### Шаг 3: Деплой на Vercel
1. Склонируйте или загрузите проект в ваш GitHub.
2. В панели Vercel нажмите **Add New Project** -> выберите этот репозиторий.
3. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` = ваш токен от BotFather
   - `TELEGRAM_SECRET_TOKEN` = случайная секретная строка для защиты вебхука (например: `my_random_secret_12345`)
   - `UPSTASH_REDIS_REST_URL` = URL базы Upstash
   - `UPSTASH_REDIS_REST_TOKEN` = Токен базы Upstash
   - `APP_URL` = публичный URL вашего Vercel-приложения (например `https://my-zazyvala-bot.vercel.app`)
4. Нажмите **Deploy**.

### Шаг 4: Регистрация вебхука в 1 клик
После завершения сборки:
- Откройте в браузере главную страницу вашего бота: `https://my-zazyvala-bot.vercel.app/`
- Нажмите кнопку **«Зарегистрировать вебхук»** (или перейдите по адресу `https://my-zazyvala-bot.vercel.app/api/setup?action=set`).
- Бот ответит JSON-сообщением: `{"ok": true, "message": "Webhook successfully configured!"}`.

Готово! Добавьте бота в ваш чат и выдайте права администратора.

## 💻 Локальная разработка и тестирование

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск тестов
```bash
npm test
```
Все 19 тестов проверяют экранирование HTML, zero-width ссылки, пачки, хранилище, права, кулдауны и маршрутизацию команд.

### 3. Локальный сервер
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`. Вы можете открыть красивую панель мониторинга в браузере или пробросить локальный порт через ngrok:
```bash
ngrok http 3000
```
Затем установить вебхук:
```bash
curl "http://localhost:3000/api/setup?action=set"
```

## 🔒 Безопасность
- **X-Telegram-Bot-Api-Secret-Token**: Каждый входящий запрос проверяется на соответствие секретному токену, предотвращая подделку вебхуков.
- **Проверка прав администратора**: Вызов меню настроек и изменение критических параметров защищены верификацией через `getChatMember`.
- **Экранирование HTML**: Все пользовательские имена, позывные и тексты сообщений автоматически экранируются для защиты от HTML-инъекций и сбоев парсера Telegram.
