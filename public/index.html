⚡ Оптимизации под Vercel

  • 🚀
    Фоновая отправка (waitUntil)
    Вебхук Telegram мгновенно получает 200 OK, а рассылка пачек продолжается в фоне без таймаутов.
  • 📦
    Upstash Redis Pipeline
    Все профили участников загружаются за 1 HTTP-запрос (~15 мс) без пула соединений.
  • 👻
    Скрытый режим (Zero-Width)
    Тегает участников невидимыми ссылками — участники получают push-уведомление, а чат остается чистым.
  • 🛡️
    Защита от флуда и кулдаун
    Атомарный TTL в Redis блокирует спам без нагрузки на серверную функцию.

📖 Основные команды бота

/all [текст] или /tag Созвать всех активных участников группы (пачками по 5 для 100% доставки пушей)
/admins [текст] Созвать всех администраторов чата через прямое API Telegram
/setme <позывной> Установить личный позывной/эмодзи (например: /setme ⚡ Тор)
/out и /in Отписаться или подписаться на уведомления от /all (уважение к личному покою)
/settings Интерактивная панель: скрытый режим, кулдаун, размер пачки, права доступа
/lists, /create_list, /call Создание пользовательских списков (игры, дежурные, отдел)
/stats Статистика базы участников, активных и отписавшихся
